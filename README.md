# 农业政策概论 · 课件站点

本目录可直接作为静态网站发布（无需构建）：

- `index.html` 课程首页
- `lecture-02.html` 第二讲 农业政策背景（上）
- `lecture-03.html` 第三讲 农业政策背景（下）
- `.nojekyll` 让 GitHub Pages 原样发布

## 用 GitHub Pages 发布（网页操作，约 5 分钟）

1. 登录 GitHub → 右上角 **+** → **New repository**，名称如 `agpolicy`，选 **Public**，创建。
2. 在新仓库页点 **uploading an existing file**，把本目录下全部文件（含 `.nojekyll`）拖进去 → **Commit changes**。
3. 仓库 **Settings → Pages**：Source 选 **Deploy from a branch**，Branch 选 `main` / `/ (root)` → **Save**。
4. 1–2 分钟后访问：`https://900112.xyz/agpolicy/`

更新课件时，重新上传同名文件覆盖即可。
